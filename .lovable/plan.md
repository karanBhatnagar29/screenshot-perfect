# Nexora enterprise website

## Build
- Recreate the reference’s spacious enterprise layout, crisp white-and-navy palette, confident typography, sticky navigation, responsive mega menus, and full-width visual sections with original Nexora branding and imagery.
- Build the complete homepage sequence: hero, partner/certification strip, configurable sample metrics, company story, services, emerging technology, categorized technology tabs, industries, filterable illustrative portfolio, clearly fictional testimonials, delivery process, engagement models, final CTA, and a detailed footer with a working newsletter form.
- Add complete About, service overview and service-detail, industry overview and detail, portfolio and case-study detail, hire developers, blog listing and article detail, contact, privacy, and terms pages. Give every content page unique SEO metadata and working internal links.
- Store validated contact and newsletter submissions in Lovable Cloud with anonymous insert-only access and no public read access. Clearly identify sample metrics and illustrative work; do not imply real customers or endorsements.
- Verify desktop and mobile rendering, navigation, interactive filters/tabs/menus, form validation and successful storage, and the project’s existing routing tests.

## Technical approach
- Use TanStack Start file-based routes and shared site data/components; retain the existing router and Cloud auth middleware.
- Use the existing Tailwind v4 semantic tokens, Lucide icons, and native React interactions with reduced-motion support; avoid adding animation dependencies unless necessary.
- Add the required table grants, row-level security, and insert-only policies through the managed migration workflow; keep browser configuration publishable and secrets server-only.
